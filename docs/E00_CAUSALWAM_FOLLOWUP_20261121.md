# CausalWAM × OpenWAM M29 后续实验

2026-11-21 登记。新增实验排在已有冻结微调、同权重 ON/OFF、从头训练三阶段及其条件确认任务之后。

## 论文提供了什么证据

CausalWAM 在正则性、观测等价和机制支持集稀疏等条件下给出可识别性结果。机器人实现用动作查询对 clean context 的 attention mass 构造可训练的替代目标。在 RoboCasa365 的 17 个任务上，论文报告宏平均成功率从 24% 升到 43%，13 个任务有提升。作者还在 CWAM 得分最高的 4 个任务上做了固定权重的上下文干预，原模型、仅保留所选视觉 token、等数量随机保留三者的平均成功率分别为 71.3%、60.3%、24.5%。这个子集经过结果筛选。主对照同时改变了 Router 和稀疏目标，两个因素的独立贡献仍需额外对照。[论文 §3–5、表 2、附录 E/H](https://arxiv.org/html/2610.42096v1)

## 在 M29 上隔离稀疏项

M29 的 30 层动作与视频联合注意力已能传递视觉信息。新增分支位于动作解码器之前，由动作 hidden 查询最后一层前视和腕部视角的 98 个 clean token。文本通过既有路径进入模型。冻结的 V-JEPA 2.1 视觉编码器、RynnBrain 离线文本、dense 主路径和世界预测损失都沿用前序协议。论文使用 Cosmos 3、任务与视觉 context、Router 学习率倍率 5。这里沿用 Dense 对照的学习率以隔离正则的作用。[原 M29 结构说明](CAUSALWAM_M29_ROUTING_RESEARCH_PLAN.md)

| 训练组 | 权重及角色 |
|---|---|
| 无 Router | 复用前序 seed 42 从头训练的最终权重，衡量添加整条分支的收益 |
| FP32 Dense | 复用前序同 seed 最终权重，作为稀疏组的主对照 |
| FP32 Sparse | 唯一新增的完整训练，10,690 步，与 Dense 匹配数据顺序、主干初值、训练预算、学习率、512 宽度、8 heads、初始 gate 0.01。每个 head 和有效 action query 惩罚 Top-32 以外的 attention mass。正则系数从第 1,000 步起用 4,000 步线性升到 0.01 |

以保存的训练配置和数据顺序证据做匹配校验，记录首次实际前向的 gate dtype 和训练过程的 Top-32 mass、熵、gate 与残差比例。推理时维持 soft attention。历史 BF16 微调的 B1/B2 结果另列并只用于背景。

## 预先指定的判断方法

- 主指标为最终权重在预先锁定的 600 个预留 LIBERO-Plus 变体上的 Sparse − Dense 成功率差。相机、光照、背景各 200 条。与旧 pilot 不共享变体。600 条旧 pilot 为次指标。三个模型用相同任务、种子、初态、推理和渲染配置，按任务记录救回和新增失败。保留与无 Router 基线的第二项比较。
- 机制诊断预定为标准 LIBERO 四个 suite 的 task 2、初态 0，每个 checkpoint 使用相同观测及去噪噪声比较同一模型中的干预。仅移除新增分支 Top-32 的 value 贡献，再与随机移除 32 个、等质量衰减作比较。记录移除质量、value 变化、平移、旋转、夹爪变化。主干仍能读到视觉信息。这个设计估计分支对动作的影响，与论文限制整个动作头可见上下文的闭环充分性问题不同。
- 判读以预留集的配对成功率为先。仅观察到 attention 集中或移除 Top-32 后动作变化较大，仍不足以判断闭环收益或识别因果对象。训练种子固定为 42，预留集共享基础任务，外推范围限于该协议。结果好坏都记录。
